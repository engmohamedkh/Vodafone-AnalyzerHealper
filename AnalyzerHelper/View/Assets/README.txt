Vodafone logo for Analyzer Helper header
========================================

1. Get the official Vodafone logo from your company's brand site or:
   https://www.vodafone.com (brand resources / VOIS)

2. Save the logo as:  vodafone-logo.png
   - Use a white or light version on transparent background (for the red header).
   - Recommended size: height about 28–36 px, width to match aspect ratio.

3. Place  vodafone-logo.png  in this folder:
   AnalyzerHelper\View\Assets\

4. Rebuild the app. The logo will be copied to the output and shown in the header.
   If the file is not present, the header shows "Vodafone" text instead.
