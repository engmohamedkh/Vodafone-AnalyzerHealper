# Models

**Purpose:** Data classes, enums, and DTOs (properties only; minimal logic).

- **RuleLevel**, **RuleCheckResult** – Report finding severity and row data.
- **FixCategory** – Auto fix vs need user interaction.
- **SolutionFileItem**, **SolutionTreeNode**, **SolutionTreeBuilder** – File tree and folder structure for the sidebar.
- **AnalyzerReportRow** – One row in the Report grid.
- **RoleFixItem** – One rule item in No/Need interaction tabs (with checkbox).
- **RoleReference** – Reference list of workflow role names.

Edit here when you change report columns, file tree shape, or rule list item fields.
